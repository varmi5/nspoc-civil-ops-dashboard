Two terms come up a lot on this page:

  • Conjunction: two tracked objects passing close together in orbit. It's what we call a collision risk before it's assessed. MSH tracks these as conjunction-events.
  • Fragmentation: a breakup incident, where an object splits into new trackable debris. MSH tracks these as fragmentation-events.

NSpOC's own report has a single \"Collision Risks to UK Satellites\" figure (1,285 in its May 2026 report), and a separate \"Alerts Issued\" line. We don't show an equivalent to the first number on this page: MSH's raw monthly screening count runs around 50,000-60,000, every conjunction MSH's software flagged that month, the overwhelming majority wide misses with no real risk, so far from NSpOC's figure that showing it, even caveated, read as simply wrong. It's been dropped entirely. The chart below shows the closest available proxy for \"Alerts Issued\" instead: screenings that crossed the analysis probability threshold (> " + viewModel.analysisThreshold + ") that month. MSH has no literal \"alert\" concept for conjunctions, so this is a proxy, not NSpOC's own alert figure. See Data sources for the full investigation.
